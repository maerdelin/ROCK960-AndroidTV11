# Upstream baseline

The build is intentionally pinned to one BSP generation.

- ASUS manifest repository: https://github.com/TinkerBoard-Android/rockchip-android-manifest
- branch: `android11-rockchip`
- manifest: `tinker_board_2-android11-2.0.8.xml`
- default project revision/tag: `tinker_board_2-android11-2.0.8`
- included AOSP manifest: `android-11.0.0_r46.xml`
- AOSP supplement tag: `android-11.0.0_r46`

The controller does not follow `main`, `master`, or a moving RK3399 development branch for the build baseline.
